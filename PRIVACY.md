# Приватность Blinkwell

Актуально для публичной Mac-версии 0.5.4.

## Что используется

- Длительность с последнего системного ввода — для оценки простоя. Содержимое нажатий не читается.
- События сна, выключения экрана и смены доступности сессии — для приостановки и возобновления таймеров.
- При включённой соответствующей настройке — флаги Core Audio, показывающие использование аудиовхода. Аудиопоток не открывается и звук не записывается; названия приложений для этой функции не собираются.

## Что сохраняется

Статистика в локальной SQLite: дневные итоги, секунды активности по 15-минутным интервалам и время/вид завершённых перерывов. Настройки сохраняются в UserDefaults.

Исторические идентификаторы сохранены для совместимости: `community.pause.macos`, каталог `~/Library/Application Support/Pause/`, файл `statistics.sqlite`. Название Blinkwell не требует переноса прежней статистики.

Сохранение активности происходит примерно каждые 30 секунд, перед сном и при штатном выходе. При аварийном завершении последние секунды могут потеряться. Текущий сеанс, ручные режимы и неразобранное уточнение простоя находятся в памяти.

## Чего нет

Нет аналитики, аккаунта, облачной синхронизации, захвата экрана, записи нажатий, звука и видео. Текущий исходный код Mac-клиента не содержит экспериментального клиента синхронизации. Внешние справочные ссылки открываются только по нажатию; их сайты имеют собственные правила.

## Проверка обновлений

Sparkle 2.10.0 загружает подписанную ленту с raw.githubusercontent.com и пакет новой версии из GitHub Releases. Проверка запускается по кнопке; фоновую проверку можно включить отдельно. Автоматическая установка выключена.

Системный профиль Sparkle отключён. Статистика, настройки, сведения об активности и содержимое экрана не отправляются. GitHub и его CDN получают обычные сетевые данные запроса, включая IP-адрес и технические HTTP-заголовки. Загруженные пакеты и лента проверяются по встроенному открытому ключу Ed25519. Закрытый ключ находится только у разработчика.

## Управление

- «Статистика → Удалить статистику» очищает локальную историю.
- Определение использования микрофона, уведомления и автозапуск можно отключить.
- Закрытие окна оставляет приложение работать; ⌘Q завершает его.

При сообщении об ошибке не загружай базу статистики, настройки или скриншоты с личной информацией без проверки их содержимого.
